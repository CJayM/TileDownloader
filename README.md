# Tile Downloader

Приложение на Python для скачивания тайлов спутниковых карт с Яндекс Карт и их хранения в локальной базе данных SQLite для автономного доступа.

## Особенности

- 🌍 **Загрузка спутниковых тайлов**: Скачивает высококачественные спутниковые снимки с Яндекс Карт
- 💾 **Хранение в SQLite**: Эффективно хранит тайлы в локальной базе данных с таблицами для каждого уровня масштабирования
- 🔄 **Функция возобновления**: Автоматически возобновляет загрузки с места остановки
- ⚡ **Асинхронная обработка**: Использует asyncio для эффективных параллельных загрузок
- 🛡️ **Обработка ошибок**: Надежная обработка ошибок с механизмами повторных попыток
- 📊 **Отслеживание прогресса**: Отслеживание прогресса в реальном времени с оценкой времени

## Требования

- Python 3.x
- Необходимые пакеты Python:
  - asyncio
  - aiohttp
  - sqlite3 (обычно включены в Python)

## Использование

### Быстрый старт

Запустите приложение с помощью предоставленного скрипта:
```bash
./run.sh
```

Или запустите напрямую:
```bash
python downloader.py
```

### Конфигурация

Приложение можно настроить, изменив константы в файле `downloader.py`:
- `MAX_ZOOM`: Установите максимальный уровень масштабирования для загрузки (по умолчанию: 14)
- `THREAD_COUNTS`: Установите количество параллельных потоков загрузки (по умолчанию: 4)

## Как это работает

1. Приложение перебирает уровни масштабирования от 1 до максимального
2. Для каждого уровня масштабирования систематически скачиваются все тайлы (2^zoom × 2^zoom тайлов)
3. Тайлы сохраняются в базе данных SQLite в отдельных таблицах для каждого уровня масштабирования
4. Прогресс отслеживается в файле `settings.pickle` для возможности возобновления прерванных загрузок
5. Приложение пропускает тайлы, которые уже были загружены

## Структура проекта

- `downloader.py` - Основная логика приложения
- `db.py` - Операции и управление базой данных
- `utils.py` - Вспомогательные функции
- `run.sh` - Скрипт выполнения
- `tiles2.db3` - База данных SQLite, содержащая загруженные тайлы
- `settings.pickle` - Состояние загрузки для сохранения

## Хранение данных

- Каждый уровень масштабирования получает свою собственную таблицу базы данных (z1, z2, z3 и т.д.)
- Тайлы хранятся с координатами X, Y и двоичными данными изображения
- База данных использует режим WAL для лучшей конкурентности

## Устранение неполадок

- **Сетевые ошибки**: Приложение включает логику повторных попыток для сетевых проблем
- **Отслеживание прогресса**: Если возникнут проблемы, проверьте файл `settings.pickle` для текущего состояния
- **База данных**: База данных SQLite использует режим WAL, что позволяет одновременные чтение/запись
