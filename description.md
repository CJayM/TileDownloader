# Описание проекта Tile Downloader

## Обзор проекта

Tile Downloader - это приложение на Python, предназначенное для систематического скачивания тайлов спутниковых карт с сервиса Яндекс Карты. Основная цель этого приложения - создать автономное хранилище тайлов карт, к которому можно получить доступ без подключения к Интернету.

## Основная функциональность

### Загрузка тайлов
- Скачивает тайлы карт с сервиса спутниковых карт Яндекс
- Использует конечную точку: `https://core-sat.maps.yandex.net/tiles?l=sat&x={x}&y={y}&z={zoom}`
- Скачивает тайлы для нескольких уровней масштабирования (настраивается, по умолчанию до уровня 14)

### Хранение данных
- Хранит загруженные тайлы в базе данных SQLite (`tiles2.db3`)
- Каждый уровень масштабирования имеет свою таблицу в базе данных (z1, z2 и т.д.) со схемой:
  - x: координата X тайла
  - y: координата Y тайла
  - image: двоичные данные изображения тайла
  - ext: расширение файла (по умолчанию 'png')

### Управление состоянием
- Отслеживает прогресс загрузки с помощью файла pickle (`settings.pickle`)
- Сохраняет текущий уровень масштабирования и индекс тайла
- Реализует функцию возобновления для продолжения после прерываний
- Использует буферизацию ячеек для эффективного обновления прогресса

## Архитектура

### Компоненты
- **downloader.py**: Основная логика приложения с асинхронной функциональностью загрузки
- **db.py**: Операции с базой данных с управлением подключениями и безопасностью потоков
- **utils.py**: Вспомогательные функции для индексации тайлов и форматирования времени
- **run.sh**: Скрипт выполнения, который обновляет и запускает приложение

### Технологический стек
- Python 3.x
- Асинхронное программирование с asyncio
- HTTP-запросы с aiohttp
- SQLite для хранения данных
- Параллельная обработка загрузок

### Особенности производительности
- Настраиваемые параллельные потоки загрузки (по умолчанию: 4)
- Оптимизация на уровне строк для пропуска полностью загруженных строк
- Периодическое сохранение состояния (каждые 60 секунд)
- Эффективное отслеживание прогресса с оценкой времени

## Параметры конфигурации

- `MAX_ZOOM`: Максимальный уровень масштабирования для загрузки (по умолчанию: 14)
- `THREAD_COUNTS`: Количество параллельных потоков загрузки (по умолчанию: 4)
- `DB_FILE`: Имя файла базы данных (по умолчанию: "tiles2.db3")
- Постоянство состояния с классом Settings, управляющим состоянием загрузки

## Обработка ошибок и отказоустойчивость

- Обработка сетевых ошибок с логикой повторных попыток
- Обработка ошибок базы данных с изящным сбоем
- Обработка тайм-аута семафора
- Периодические операции фиксации для поддержания целостности базы данных

## Сценарии использования

Это приложение идеально подходит для:
- Создания автономных карт для областей с ограниченным подключением
- Архивирования спутниковых снимков для определенных регионов
- Создания пользовательских репозиториев тайлов карт
- Предварительной загрузки данных карт для приложений, требующих автономной работы
